# 世界设定总纲

> 回答三个问题：**这是什么时候、在哪里、社会怎么运转。**
> 上位依据：`故事架构.md`（法则与境界）、`设定补丁.md`（星空万族同体系）。

---

## 一、时代：公元 2187 年

### 为什么是这个时代（设计说明，不必写进正文）

- **保留现实质感**：城市、热武器、电子设备、殡仪馆、黑市——微观描写必须有现实对照物，读者才能"看见"细胞和分子。纯异世界会让这套物理悬空。
- **容纳星空格局**：人类已走出地球，才装得下"世人向外求索星空诸天"。
- **制造时代逆流**：这个时代所有的技术、资本、荣耀都在"往外走"，主角"往里走"才是真正的逆行。

### 人类现状

| 项 | 设定 |
| -- | ---- |
| 人口 | 约 110 亿（地球 80 亿 + 太阳系殖民地 30 亿） |
| 政体 | 地球联合体，下设 7 大区，各区高度自治 |
| 疆域 | 地球全境、月球工业带、火星三城、木卫二采冰站 |
| 深空 | 代际星舰「远征号」40 年前出发，目标比邻星系，至今**无任何回音** |
| 技术主流 | 曲率推进、恒星工程、宏观材料学、能量武器——**全部是"向外"的宏观路线** |
| 技术禁区 | 微观结构研究（见下） |

### 关键历史事件

| 年份 | 事件 | 真相 |
| ---- | ---- | ---- |
| 2061 | 「渊海计划」启动：联合体秘密研究微观结构改写 | 官方从未公开 |
| 2093 | **沧城微观崩塌事件**：全城 1/4 区域物质结构瞬间崩解，11 万人死亡 | 官方定性为「化工储罐连锁爆炸」。真相是渊海计划实验失控，崩解至今未停止，那片区域被称为**塌陷带** |
| 2095 | 《微观安全公约》订立：全球禁止非授权微观结构研究 | 违者最高终身监禁；「结构师」被列为高危职业，需持证、登记、受监控 |
| 2147 | 远征号启航 | 全人类的希望工程，官方每年播报"一切正常" |
| 2184 | 沈砚之妹沈雾死亡，诊断书写「多器官渐进性结构失效，原因未明」 | 与塌陷带残留物有关（伏笔） |
| 2187 | **故事开始** | — |

## 二、地点：沧城（全书主舞台）

### 基本盘

- 旧工业港城，人口 870 万，联合体东海岸第七区
- 曾经的造船与化工重镇，2093 年后一蹶不振，现在是"联合体最不想提起的城市"
- 年平均日照 92 天，常年阴雨，空气里有铁锈和消毒水的味道

### 三个区（全书 80% 的场景在这三块地方）

| 区域 | 特征 | 作用 |
| ---- | ---- | ---- |
| **老城区** | 密集、破败、人情社会。锈街、第二殡仪馆、老式筒子楼、24 小时面馆 | 主角的日常，前期全部剧情 |
| **塌陷带** | 面积 62 平方公里，物质结构持续崩解。地面会突然变脆、金属会自己长霉、进去的人十不存一。官方禁区，实际是黑市与拾荒者的天堂 | 中期主战场，所有"沉渣"来源 |
| **新区** | 玻璃幕墙、无人机航道、秩序局驻地、星穹教团分部、联合体办事处 | 权力中心，主角最格格不入的地方 |

### 老城区的建筑状况（写场景前必读，防"楼太坚固"这类硬伤）

沧城的科技水平是 2187 年的，但**老城区的楼不是**。这里存在一个刻意的落差：

| 层 | 状况 | 原因 |
| -- | ---- | ---- |
| 新区 | 玻璃幕墙、自清洁涂层、模块化重建，二十年一换 | 有钱，且要好看 |
| 老城区 | **大多数楼龄 100-150 年**，混凝土碳化、钢筋锈蚀、防水层早已失效 | 2093 后城市衰退，没人投钱维护，只做最低限度的"不塌" |

**三条铁律**：

1. **老楼不"坚固"，只是"没塌"**。能站住靠的是结构冗余和运气，不是质量。承重墙里能掏出空鼓，地下室常年渗水，管道是几十年前换过一次再没动过的
2. **任何管线、保温、密封材料，只要超过三十年，一律视为已失效**。墙里存的不是保温棉，是水；管道里流的不是自来水，是锈
3. **老城区的冷不是"设计出来的"，是失修的结果**。地下室比地面低两度，靠的是土温和常年渗水的湿墙，不是空调也不是保温层

> **写作提示**：沈砚是遗体修复师，他判断建筑的方式和对尸体的判断是同构的——**先摸温度，再看哪里先坏**。写老楼就用这个视角，不要用建筑师的视角。

---

### 关键地点清单

1. **第二殡仪馆**：主角工作地。地下二层有一间没人用的遗体冷藏室，被他改成了观测室
2. **锈街**：黑市。卖沉渣、卖假证、卖"能多活五年"的结构修补
3. **三号坑**：塌陷带中心，直径 400 米，深不见底。崩解仍在缓慢进行
4. **秩序局微观管控科**：沧城分部，编制 41 人，主管周牧
5. **老城区面馆"三两面"**：主角每天都去，老板是个话多的老头（重要的日常锚点）

## 三、社会如何运转（写场景前必读）

### 1. 超凡者是公开的，但被污名化

- 「结构师」是合法职业，但必须持证、登记、接受秩序局监控
- 媒体长期宣传：结构师是危险品，塌陷带就是他们搞出来的
- 普通人见了结构师会绕道走，孩子会被教育"不要跟会改东西的人说话"
- 高境强者（溯原以上）反而被各国礼遇，因为他们是战略威慑——**底层被歧视，顶层被供着**，这个反差本身就是戏

### 2. 军队与热武器

- 军队全部走宏观路线：动能炮、能量束、电磁脉冲、轨道打击
- **对凝元境以下有效**（血肉之躯挡不住），**对溯原境以上基本无效**（材质本身被改写）
- 所以国家对待高境强者的方式是：**收买、监控、暗杀，而不是正面开战**
- 军队里有一支特殊编制「灰隼」，专门处理结构师事件，装备是"陌生材料"（预演不出来的材质）

### 3. 医疗

- 主流医学是宏观修复：手术、药物、器官打印
- **微观诊断被视为伪科学**，持证结构师不允许行医
- 所以主角的"看伤"能力只能在地下进行——这直接构成他的生存方式与违法风险
- 富人会花大价钱找黑市结构师"修补"（延缓衰老、清除早期病变），这是锈街最赚钱的生意

### 4. 普通人的日常质感（防止世界悬空）

- 通勤靠磁轨与共享无人车，老城区还是自行车
- 食物多为合成蛋白，真肉是奢侈品
- 通讯用腕带式终端，塌陷带内无信号
- 新闻每天播"远征号一切正常"，播了 40 年，没人再认真听
- 大多数人一辈子不会遇到结构师，但都听说过塌陷带

### 5. 钱与权

- 通用货币：联合体信用点
- 塌陷带的沉渣交易是灰色经济支柱，一年流水堪比沧城全年税收
- 真正管着沧城的不是市政府，是**秩序局**和**星穹教团**

## 四、写场景时的三条硬约束

1. **任何超自然现象都要能落到物理上**：地板突然变脆是因为结构崩解，不是因为"阴气重"
2. **塌陷带不是鬼屋**：它的恐怖来自"可计算但无法预测"——进去前你永远不知道哪块地会塌
3. **普通人不知道真相**：他们以为塌陷带是化工事故，只有极少数人知道那是微观崩塌
