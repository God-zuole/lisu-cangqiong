# 修炼体系（下沉法）

> 依据：`故事架构.md` 第一节第 4 条「修炼的本质是不断微缩感知层级、解锁粒子操控权限、扩大微观干涉领域」。
> 本文件只回答一个问题：**这三件事具体怎么做。**
> 不新增力量来源，不引入任何能量池。

---

## 一、总纲：修炼就是三件事

| 环节 | 做什么 | 决定什么 | 周期 |
| ---- | ------ | -------- | ---- |
| **观测** | 日复一日看真实的微观结构 | 知识储备 + 感知精度 | 每日，贯穿一生 |
| **下沉** | 承受对应层级的真实创伤，把感知"撞"进下一层 | 粒子层级（境界） | 数年一次，赌命 |
| **固化** | 下沉后 72 小时内完成结构自洽 | 境界是否真的留下 | 一次性，过了就废 |

一句话：**观测决定你能改多准，下沉决定你能改多细，固化决定你改的算不算数。**

---

## 二、下沉法（核心机制，全书最残酷的设定）

### 原理

人的感知天生停在宏观层，看不见细胞，更看不见分子。想让感知"降"到下一层，**唯一的办法是被那一层的力量真正伤到**——不是理解，不是冥想，是**亲身承受**。

为什么？因为感知的边界由"痛觉"划定。只有当你身体的一部分正在分子层面上被撕开时，你的感知才会被那一瞬间的剧痛强行拉到那一层，看见它。

**没被伤过的东西，你永远看不见。**

### 各境突破条件（前五境锁死，后四境留原则）

| 突破 | 需要的创伤（不可替代） | 危急性 | 常规耗时 |
| ---- | -------------------- | ------ | -------- |
| 观微 → 凝元 | **分子级崩解**：全身 30% 以上组织同时被分子结构破坏（重度化学灼伤、深部冻伤、全身性腐蚀），且必须在创伤持续期间睁着眼观测 | 死亡率约 60% | 常人 8-15 年 |
| 凝元 → 溯原 | **原子键断裂**：承受一次足以打断原子键的能量入射（高压击穿、急性放射病 IV 度以上、近距离电磁脉冲） | 死亡率约 75% | 常人 20-30 年 |
| 溯原 → 逐虚 | **电子失控**：主动进入电磁秩序被彻底打乱的区域（雷暴核心、强磁场塌陷区），让自身电子流先乱掉再复位 | 死亡率约 85% | 常人 40 年以上 |
| 逐虚 → 破尘 | **核级创伤**：承受原子核层面的震荡（核爆边缘、反应堆失控核心） | 存活记录 9 例 | 无统计意义 |
| 破尘 → 归墟 | **粒子混沌**：进入基本粒子秩序崩解的区域（上古"塌缩带"、微型塌缩体边缘） | 存活记录 2 例 | — |
| 归墟 → 千微 | **自循环建立**：在自身内部同时维持 12 个以上互不干扰的领域循环，持续 49 天不崩 | 崩塌即自身结构解体 | — |
| 千微 → 一宙 | **以身为种**：用自身粒子重构一整颗星体的物质秩序，且重构后星体不塌 | 失败则自身被反噬成尘埃 | — |
| 一宙 → 微道独尊 | **印证**：亲眼确认"宏观为虚妄"并接受它——不是力量关卡，是认知关卡 | — | — |

### 三条铁律

1. **创伤必须真实**：模拟、麻醉、药物替代一律无效。这是全书最硬的一条，也是所有强者稀少的根本原因
2. **必须清醒观测**：昏迷、闭眼、失神的一律不算，白挨一次伤
3. **同一层不能试太多次**：每次失败都会留下永久损伤，第三次之后基本没机会了

### 固化窗口

下沉成功后，**72 小时内**必须完成"结构自洽"——把新解锁的粒子层纳入自身运转秩序。

- 成功：境界坐实
- 超时：感知退回原层，且**终身不得再靠同一层创伤突破**（这条路彻底废了）
- 部分成功：境界留下但残缺（领域半径只有正常值的三分之一，且终身不涨）——书里叫「残境」

> 「残境」是很重要的写作资源：大量凝元境、溯原境其实都是残境，这解释了为什么高境强者能一个打十个同境。

## 三、观测（决定精度与知识储备）

### 观测需要样本

**没看过的东西改不了。** 这句话是全书战斗逻辑的地基。

- 想改石头，得看过石头的分子排列
- 想改骨头，得看过骨头的结构
- 想改一个从没见过的外星材料，得先花时间看

### 观测的三个层次

| 层次 | 内容 | 对应能力 |
| ---- | ---- | -------- |
| 看见 | 知道那里有什么 | 能诊断、能判断 |
| 看清 | 知道结构怎么排的 | 能复现、能预演 |
| 看透 | 知道这结构为什么这么排、错在哪 | 能改、能改得更好 |

主角的优势在于他常年在**看透**这一层，因为他干的活就是看别人的身体。

### 感知范围 ≠ 干涉域（重要区分）

- **感知范围**：能看多远。观微境可以看到整栋楼里所有人的细胞（只是看不细）
- **干涉域**：能改多大。观微境只能是零

**看得见，改不了**——这是全书前期的核心痛苦，也是很多场戏的张力来源：他眼睁睁看着一个人体内正在崩解，却一根手指都动不了。

## 四、境界内部分段（撑住几百万字的节奏）

每一境内部固定三段，**不新增境界，只是同一境的不同完成度**：

| 段位 | 标志 | 领域半径 | 说明 |
| ---- | ---- | -------- | ---- |
| **初窥** | 刚解锁，只能做最基础的操作 | 本境下限 | 刚下沉成功，操作生涩，耗时是熟练者的 3-5 倍 |
| **贯通** | 常规操作稳定，可连续使用 | 本境中段 | 大部分强者停在这里 |
| **极域** | 触摸本境上限，精度与速度都到顶 | 本境上限 | 极少数，通常是一方势力的核心 |

> 例：凝元境初窥 5 米、贯通 12 米、极域 20 米。极域凝元境能打三个贯通凝元境。
> 这套分段让"同境对抗"有梯度，避免境界一升级就天下无敌。

## 五、主角的特殊性（金手指，且完全合规）

**沈砚没有天赋。他有的是一件别人没有的东西：他比别人早十年解锁了"绝对自愈"。**

因果链：

1. 观微境权限是「修正自身细胞、绝对自愈」
2. 下沉法要求"承受真实创伤且保持清醒"
3. 常人在创伤中等死，等不到观测完成就死了
4. 他能一边被烧穿、一边修回来——**所以在别人必死的创伤里，他能活到看见那一层**

于是：

- 他不是修炼快，他是**敢死**
- 别人一辈子赌一次，他敢赌十次
- 代价是：每次赌完，身上都多一块修不回来的地方（详见 `代价体系.md`）

> 这条金手指的铁律：**只能用于"承受"和"修复"，绝不能用于"攻击"或"防御加成"。** 一旦写成"他能自愈所以打不死所以无敌"，全书就崩了。
