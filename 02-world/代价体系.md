# 代价体系

> 依据：`故事架构.md` 明令禁止能量体系（无灵气、无真元），因此"用能力会累"必须有**物理解释**。
> 本文件定死三类消耗与一条核心法则，全书不得出现第四种消耗方式。

---

## 一、核心法则：预演法则（本书最重要的原创设定）

**想改写外部物质，必须先在自身体内复现一遍该结构。**

### 为什么

微观干涉是"用自己已经掌握的结构范式"，去覆盖目标物的结构。而你唯一能直接、完整、实时掌控的结构样本，是**你自己的身体**。

所以要改外部的东西，流程永远是：

```
看清目标结构 → 在自己体内找到对应组织 → 按目标结构改写自己那部分组织
→ 确认成功（且自己没死） → 把这个范式"推"到外部目标上
```

### 这意味着什么（写作上的巨大红利）

1. **每次对外动手，都是先在自己身上烧一次**
   - 想把石头变金属，得先在自己骨头上试一遍金属的排列
   - 想让敌人骨头散架，得先在自己手上试一遍"结合力消失"
2. **陌生结构 = 高风险**
   - 对没见过的材料，预演时可能直接把自己改废
   - 所以强者遇到"上古造物""外星材料"会本能退缩——**这是中期战斗的重要变量**
3. **主角的每一次胜利，身上都多一道伤**
   - 战斗写的是"他为了改那面墙，先把自己的小臂改成了类似砖的结构"
   - 这是全书最有辨识度的战斗描写方式

### 预演的三个限制

- **只能预演自己有的东西**：想改骨骼，自己得有骨骼（改不了昆虫外骨骼，除非观测到足够多次）
- **预演有耗时**：越陌生越慢，第一次可能要几分钟，熟练后可压缩到 0.5 秒
- **预演不可逆**：改过的组织，即使改回来，也有残留损伤

## 二、三类消耗（只有这三类）

### 消耗 1：感知负荷（即时，最容易写）

维持"观测"本身是高强度神经运算，不是免费的眼睛。

| 强度 | 表现（按顺序出现） | 恢复 |
| ---- | ------------------ | ---- |
| 轻度 | 眼眶发胀、太阳穴跳、注意力涣散 | 闭眼 10 分钟 |
| 中度 | 视野边缘发灰、耳鸣、手指细微震颤、看东西重影 | 睡 4-6 小时 |
| 重度 | 短暂失明（几分钟到几小时）、偏头痛、呕吐、无法分辨距离 | 2-3 天 |
| 过载 | 视网膜出血、面部神经麻痹、短暂失语 | 数周，且可能留下永久后遗症 |

> 写作要求：**每章至少出现一次轻度以上负荷**。这是"能力有代价"最廉价也最有效的落地方式。

### 消耗 2：生理储备（预演的组织损耗）

预演本质是**在自己身上消耗真实物质**。改一次，少一点。

- 表现：体重缓慢下降、旧伤复发、关节作响、牙齿变脆、指甲出现横纹
- 观微境以上可以修回来，但要**时间和原料**（进食、睡眠）
- 高强度连续使用会进入「空转」：修得没有耗得快，人开始肉眼可见地垮

### 消耗 3：不可逆损伤（永久，最贵）

| 来源 | 代价 |
| ---- | ---- |
| 每次突破（下沉） | 永久损伤一处：器官钙化、神经坏死、单侧听力丧失、局部皮肤永久失去痛觉……（建议每次突破由作者预先指定具体部位，写进角色档案） |
| 越级强用能力 | 按超出层级差计价：超一层 = 一处器官永久损毁；超两层 = 大概率当场死亡 |
| 反复预演陌生结构 | 被预演的组织永久失去原有功能（手指不能弯曲、某段皮肤无法排汗） |
| 感知过载累计 | 视力永久下降、手抖（影响精度，形成恶性循环） |

**全书铁律**：不可逆损伤**不能靠任何东西治好**。这是硬核基调的地基，也是主角越强越残的原因。

## 三、反噬（预演失败 / 改写崩溃）

改写不是必然成功。失败的三种表现：

| 类型 | 触发 | 后果 |
| ---- | ---- | ---- |
| **回震** | 预演成功但外部推演失败 | 承受反冲：内出血、骨折、短时间失去该层感知（最轻，也最常见） |
| **错构** | 结构参数错误 | 目标物变成"不该存在的东西"——石头变成会缓慢崩解的脆物，骨头变成空心的。**不可复原** |
| **自噬** | 预演时把自己改错 | 最严重：自己的组织被错误结构覆盖，轻则截肢，重则当场崩解 |

> 写作建议：每 15-20 章安排一次**错构**或**自噬**，让读者记住"这活儿真的会死人"。

## 四、越级的代价（防"拼命就赢"）

| 越级幅度 | 短期效果 | 代价 | 成功率 |
| -------- | -------- | ---- | ------ |
| 同境内跨段（初窥 vs 极域） | 可对抗，靠知识弥补 | 常规消耗 | 视情况 |
| 越一层（凝元打溯原） | 只能在极短时间内模仿一两个动作 | 一处器官永久损毁 + 卧床数月 | < 20% |
| 越两层 | 只能做到"让对方惊讶一下" | 大概率当场死亡 | < 3% |
| 越三层以上 | **无此设定，禁止出现** | — | 0 |

---

## 五、恢复（没有丹药，只有时间）

- **唯一手段**：自身观微境权限修复 + 睡眠 + 进食 + 时间
- 没有疗伤药、没有灵丹、没有治疗术、没有"天材地宝"
- 修复他人 = 干涉对方体内结构 = 极高难度（对方的身体不是你的，预演没法做），所以**能救人的人比能杀人的人少得多**
  - 这条很关键：主角的"医者"属性天然稀缺、天然值钱、天然惹祸
