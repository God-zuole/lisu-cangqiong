# 势力与组织（敌人体系）

> 回答一个问题：**主角在跟谁打。**
> 设计原则：三层敌人，一层比一层讲道理；每一层都严格卡在 `战力规则.md` 的境界与人数上限内，不新增体系。

---

## 零、为什么必须分层

单一敌人撑不住几百万字：
- 纯非人格化的"灾变"能撑前期，撑不住中期（读者要看见"人"）
- 纯人形反派撑不住后期（格局不够）
- 所以三层并存，随主角境界逐层浮出水面

**关键**：三层不是替换关系，是**同时存在**。前期的秩序局在后期还在，只是不再是主要威胁。

---

## 第一层：生存级威胁（Ch.001-100）

### 1. 沉渣（非人格化，全书最持久的敌人）

| 项 | 内容 |
| -- | ---- |
| 是什么 | 2093 年崩塌事件遗留的**微观结构残渣**。它们不是生物，是"还在继续崩解的结构"——一种会传染的崩解 |
| 表现 | 进入人体后缓慢改写组织：外表完好，内部结构一处接一处失效。早期无症状，晚期多器官同时崩解，死亡诊断常写「原因未明」 |
| 危险性 | 不主动攻击，随物质接触扩散。塌陷带内浓度最高 |
| 能否消灭 | **不能**。只能清除个体体内的沉渣，或封锁区域 |
| 写作用途 | ① 前期所有离奇死亡案件的源头；② 主角妹妹的死因；③ 主角观测能力的"老师"——他靠看沉渣学会了很多结构知识 |

> 沉渣的存在让本书有了"案件流"的骨架：每一具离奇死亡的遗体，都是一个可独立成章的小谜题，同时推动主线。

### 2. 锈街结构师（日常对手，炮灰级）

| 项 | 内容 |
| -- | ---- |
| 构成 | 无证结构师、拾荒者、沉渣贩子、黑医。境界多为观微境残境到凝元境初窥 |
| 目标 | 活着、赚钱、别被秩序局抓 |
| 手段 | 卖沉渣、卖假修补、抢劫、灭口 |
| 对主角 | 一半是同路人，一半是威胁。主角在锈街有熟人也有仇家 |
| 能否妥协 | 能。他们不关心真相，只关心价钱 |

### 3. 秩序局 · 微观管控科（制度性敌人，最难缠）

| 项 | 内容 |
| -- | ---- |
| 性质 | 联合体执法机构，沧城分部编制 41 人 |
| 领导人 | **周牧**，46 岁，凝元境贯通。前军人，左手三根手指是假肢（追捕时被改过结构） |
| 目标 | 执行《微观安全公约》：所有非授权微观研究一律取缔 |
| 手段 | 监控登记、突击检查、追踪沉渣流向、必要时击毙 |
| 为什么难缠 | **他们不邪恶，甚至是对的**。塌陷带就是失控研究的后果，他们见过 11 万人的尸体 |
| 对主角 | 主角违法研究 + 黑市行医，是他的重点监视对象。但他也知道主角能看见别人看不见的东西，所以一直"留着一手" |
| 能否妥协 | 有限度地。周牧可以容忍主角，前提是主角不越线；一旦越线，他会亲自来 |

> 这一层是本书最锋利的道德张力：**主角在违法，执法者在做对的事。**

## 第二层：理念级敌人（Ch.100-400）

### 4. 星穹教团（外求派极端组织）

| 项 | 内容 |
| -- | ---- |
| 主张 | 答案在星空深处。「远征号」不是失联，是抵达了；人类必须倾尽所有向外走 |
| 对微观的态度 | 视为**异端**。他们认为微观研究是"往泥里钻"，是文明的自杀（因为塌陷带就是证据） |
| 规模 | 全球信众约 2000 万，正式成员约 3 万，沧城分部约 800 人 |
| 境界 | 高层以凝元境为主，有 2 名溯原境（登记在册） |
| 手段 | 舆论、政商游说、清除"内求者"（暗杀）、垄断星际资源 |
| 对主角 | 一旦发现主角在系统性研究微观结构，会被列为"必须清除的污染源" |
| 能否妥协 | 不能。理念根本对立 |
| 关键人物 | **唐枝**，24 岁，教团外围成员，星际航行学院见习领航员（详见下方人物表） |

### 5. 结构师联盟（同类竞争者，最危险的敌人）

| 项 | 内容 |
| -- | ---- |
| 主张 | 微观是真的，但真相不重要，**力量才重要**。结构师应当统治，而不是被登记、被监控 |
| 规模 | 全球约 8000 人，是唯一成体系的内求派组织 |
| 境界 | 盟主**池渊**（溯原境极域，全球 120 名溯原境之一），核心 12 人皆凝元极域 |
| 手段 | 用微观技术控制政商、贩卖"长寿修补"、控制沉渣交易、清除不服从者 |
| 对主角 | 初期会**招揽**（主角的天赋他们很想要），中期会**追杀**（主角不肯站队，还动了他们的生意） |
| 能否妥协 | 不能。他们要的是统治，主角要的是真相 |
| 为什么最危险 | 和主角走同一条路，只是目的不同。他们比任何外求派都更懂主角的弱点 |

### 6. 灰隼（军队特殊编制，工具性威胁）

- 联合体军中专门处理结构师事件的部队，约 300 人
- 全员无境界，靠**陌生材料装备**作战（材质无法预演，结构师生效打折）
- 出现时机：事件升级到需要"清场"时
- 用途：给中后期提供"正规军压场"的紧张感；也证明"没有境界的人也能威胁结构师"

## 第三层：真相级敌人（Ch.400 之后）

### 7. 上古守序者（自修复程序）

| 项 | 内容 |
| -- | ---- |
| 是什么 | 上古微观文明在崩塌前留下的**自动修复机制**。不是人，不是神，是一套还在运行的规则 |
| 为什么存在 | 当年文明崩塌，为避免残余结构继续连锁瓦解，它们把所有物质"封装"成宏观形态——**这就是宇宙的由来** |
| 目的 | 阻止任何人从内部改写结构、阻止任何人接近真相。因为一旦有人证明了"宏观是废墟"，封装就会失效 |
| 表现 | 表现为"规则"而非"角色"：某些区域会突然无法预演、某些改写会莫名失败、某些突破会被强制中断 |
| 对主角 | 从"阻碍"到"最后的对手"。它不是恶意的，它在执行保护程序 |

### 8. 真正的终极对手：宏观虚妄本身

- 所有人——包括所有星空文明、所有高境强者——都在维护这个外壳
- 因为戳破它意味着：现有世界的一切秩序、经济、信仰、生命形态，全部重建
- **所以主角最后的敌人不是某个人，是"所有人都希望他别往下看"这件事**

    │                      │
    └──(都压制)──> 内求者 ←─┘
                      │
