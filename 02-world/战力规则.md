## 一、九境能力上限速查

| 境 | 粒子层 | 干涉域上限 | 能做什么（上限） | 绝对不能做 |
| -- | ------ | ---------- | ---------------- | ---------- |
| 观微 | 细胞 | **0（仅自身）** | 自愈、免疫疾病、看清自身与近距离他人细胞 | 对外界产生任何干涉 |
| 凝元 | 分子 | 20 米 | 改变排列形态：凝冰、碎石、软化金属、紊乱肌肉 | 改变物质本质（石头变不成金属） |

## 二、数量金字塔（防战力通胀，最关键的一张表）

**全世界人口约 110 亿（含太阳系殖民地）。**

| 境界 | 全球人数 | 说明 |
| ---- | -------- | ---- |
| 观微境 | 约 40 万 | 绝大多数是"残境"，只是不会生病、伤口愈合快 |
| 凝元境 | 约 3000 | 真正能对外干涉，社会精英层 |
| 凝元极域 | 约 40 | 个体战力堪比一支连队 |
| 溯原境 | **约 120** | 一方强者，各国登记在册 |
| 逐虚境 | **17** | 每一个都是国家级战略资源，有公开姓名 |
| 破尘境 | **3** | 三人互相制衡，谁也不敢先动 |
| 归墟境 | **1** | 常年不现世，身份未知 |
| 千微境以上 | **0** | 一个都不存在 |

### 使用规则

1. 写一个新的溯原境以上角色，**必须同时说明"他占掉了 120 个名额里的哪一个"**，并在 `02-world/势力与组织.md` 登记
2. 禁止凭空出现"隐世高人"——高境强者不可能隐世，他们的存在本身就是地缘政治事件
3. 主角每升一境，**必须挤掉一个名额或创造一个新名额**（前者意味着有人死了，这是很好的剧情钩子）

## 三、五把锁（判定任何一场战斗）

### 锁 1：领域锁

目标在干涉域之外 → **能力完全无效，不许"勉强够到"**。
- 观微境：锁死，只能是零
- 凝元境：5-20 米，超出就是普通人

### 锁 2：层级锁

低层级对高层级：**只能挨打**。层级差是绝对的，与经验、技巧、意志无关。

### 锁 3：耗时锁

每次改写的耗时由境界与熟练度决定：

| 操作 | 凝元初窥 | 凝元贯通 | 凝元极域 |
| ---- | -------- | -------- | -------- |
| 简单（碎石、凝冰） | 2-3 秒 | 0.8 秒 | 0.3 秒 |
| 中等（紊乱肌肉、软化金属） | 8-10 秒 | 3 秒 | 1 秒 |
| 复杂（自身结构加固） | 30 秒以上 | 10 秒 | 4 秒 |

> 战斗写的是"谁先改完"，不是"谁更猛"。所有紧张感来自倒计时。

### 锁 4：预演锁

改写陌生结构必须先预演，预演耗时间且伤自己（见 `代价体系.md`）。
**用途**：让高境者也不能随随便便秒杀陌生目标。

### 锁 5：代价锁

任何越级、任何过载，都必须付出表内代价。**不存在"拼一下就赢了且没事"**。

## 四、同境对抗：只看四个变量

1. 感知精度（能否看出结构缺陷位）
2. **结构知识储备**（不知道的结构改不了）← 主角的胜负手
3. 控制速度（见锁 3）← 主角的短板
4. 预判（读对方的下一步改写意图）

**禁止引入的判定因素**：气、势、底蕴、意志力、血脉、天赋爆发、主角光环。

### 主角战斗的固定公式（写作模板）

```
① 他先挨一下（因为速度慢）
② 挨的同时看清对方的结构（这是他的主场）
③ 找到缺陷位（对方自己都没注意的地方）
④ 预演（自己身上先疼一次）
⑤ 一击改死（慢，但准）
⑥ 付出代价（失明/骨折/某块组织废掉）
```

违反这个公式的写法即为崩坏。

## 五、低境打败高境的四条合法路径（唯一出口）

不高境压制是绝对的，但低境可以赢，只有四种方式：

1. **信息差**：高境者不知道自己的结构有某个缺陷，低境者知道
2. **结构知识**：高境者只会改自己熟悉的物质，低境者恰好懂他不懂的
3. **环境**：把战场变成高境者不便施展的地方（狭窄、易燃、有大量陌生材料）
4. **他人的代价**：借用别人的干涉域（比如引爆一个更强者留下的结构残渣）

> **禁止**：靠突破、靠愤怒、靠"我不想输"、靠突然悟到、靠血脉觉醒。

## 六、写作红线（出现即重写）

- [ ] 低级境界打出了高级效果
- [ ] 目标在领域外却被影响到
- [ ] 越级胜利且没有对应的器官损毁代价
- [ ] 出现"气""势""意志"决定胜负
- [ ] 凭空出现设定表以外的高境强者
- [ ] 上一章重伤，这一章满状态作战
- [ ] 改写陌生材料却跳过了预演
- [ ] 用"爆发""拼命""超水平发挥"解决问题
- [ ] 战斗中突然领悟新能力（领悟可以，但只能是"想通了怎么用已有的东西"，不能解锁新层级）

## 七、每卷必做的战力自查

- [ ] 本卷出场的高境人数是否与金字塔表相符
- [ ] 主角本卷能力是否严格对应境界表
- [ ] 本卷是否有"代价"缺席的战斗
- [ ] 同境对抗是否写出了四个变量的差异，还是全靠速度
- [ ] 有没有人越级赢了却没付账
