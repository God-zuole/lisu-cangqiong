## 补丁 1：宏观与微观的边界（修「宏观无法改变微观」与「触碰即崩」的字面冲突）

### 原文冲突

- 第一节第 3 条：「宏观无法改变微观」
- 第三境效果：「瓦解敌人骨骼原子结合力：触碰即崩」

严格按字面，任何刀砍枪击都碰不到分子、原子层面，那全书战斗直接失效。

### 澄清表述（建议采纳原文之下的解释层）

**宏观力量只能破坏「表象」，不能「定向改写结构」。**

三层含义：

1. **能打断，不能改写**：一刀能砍断骨头（破坏表象），但砍不断骨头的原子键（结构仍在，只是整体断了）
2. **无方向性**：宏观冲击对微观的作用是混乱的、不可控的、无法选择的；微观干涉是精确的、可指定的
3. **不可逆性不同**：宏观砸碎的东西可以再拼回去（宏观修复），被改写结构的东西**本质上变了**，无法复原

### 由此得出的战力差

| | 普通人 / 宏观武器 | 微观者 |
| --- | --- | --- |
| 打石头 | 砸成碎块，还是石头 | 把石头改成金属，强度提升十倍 |
| 打人 | 打断骨头 | 让骨头自身的结合力消失，站着的人直接塌下去 |
| 修复 | 手术缝合、换器官 | 让受损组织重新长回原结构 |
| 上限 | 受材料与能量限制 | 受感知层级与领域半径限制 |

> 一句话总结，可直接入正文：**"他们能把东西砸烂，我能让东西不再是自己。"**

## 补丁 2：同境胜负的判定（原设定只写了层级压制）

原设定只定义"高境压低境"，未定义同境对抗，会导致中期战斗退化成"谁先动手谁赢"。

### 同境四变量（唯一判定标准，不得引入"气""势""底蕴"）

1. **感知精度**：能否看出对方结构的**缺陷位**（同等境界下，精度差一档就是生死差）
2. **结构知识储备**：知道多少种物质的微观排列范式；不知道的结构改不了
3. **控制速度**：从锁定粒子到完成改写的耗时——这是同境对抗的**主要胜负手**
4. **预判**：读对方下一步要改哪里

### 主角的定位（写战斗时的固定原则）

- 主角赢在 **2（知识储备）** 与 **4（预判）**，因为他一生都在看，没在打
- 主角输在 **3（速度）**，因为他每次改写都要先在体内预演，天生比天赋型慢半拍
- 所以主角的战斗永远是"**慢半拍但算准了**"：先挨一下，看清结构，再一次改死
- **禁止**写主角突然爆发加快速度赢——那违反"控制速度由境界决定"

## 补丁 3：消耗的载体（原设定禁用灵气，需给"累"一个物理解释）

详见 `代价体系.md`。此处只记结论：

**没有能量池。消耗的是三类真实资源：感知负荷（神经）、生理储备（自身组织）、不可逆损伤（寿命与器官）。**

**核心机制「预演法则」**：想改写外部物质，必须先在自身体内复现一遍该结构。
于是他每次对外动手，本质都是**先在自己身上烧一次**。这就是代价的物理来源，也是本书战斗描写最独特的部分。

## 补丁 4：第一境期间的生存逻辑（观微境无法对外干涉）

这不是缺陷，这是本书前期的招牌。规则定死三条：

1. **他打不了人，但他打不死**：观微境绝对自愈，普通暴力杀不死他（但会痛、会留疤、恢复要时间）
2. **他能看见别人看不见的**：别人体内的细胞状态、结构失衡、早期崩解——现代医学查不出来的东西，他一眼看到
3. **他的武器是信息，不是拳头**：前期所有胜利都来自"他知道了别人不知道的事"，而不是打赢

> 前期战斗的正确写法：**不是他赢了，是他活下来了，而且对方发现自己的秘密被看见了。**

## 补丁 5：星空与万族的力量归属（防后期自创体系）

原设定提到"星空诸天""万族""世人向外求索"，但未说明他们的力量来源。

**锁定结论**：宇宙中所有文明、所有强者，力量**全部**来自同一套微观法则。区别只在于：

- 绝大多数文明走「向外」：宏观工程、星舰、恒星改造——**在废墟外壳上爬**
- 极少数文明走「向内」：微观结构改写——**在壳内部作业**
- 上古微观文明是唯一走到过第九境的文明，它崩塌了，留下这个外壳

**禁止**出现"外星另有体系""另一种道""异宇宙法则"。他们的强，只能是境界更高、领域更大、看到的粒子更小。

> 由此得出全书最锋利的一句话，可直接用作后期核心台词：
> **"你们飞了十万光年，还是在壳外面。壳是我修的。"**

## 补丁 6：残留共振（旧疤为什么会在沉渣附近发烫）

> 来源：Ch.001 正文已用（针进第三下时左手虎口发烫、章末"已经不烫了"），设定未定义，属"正文领先设定"。此条为追认，不新增力量体系。

**机制**：人体组织一旦被活跃沉渣改造过而没被修干净，那一片组织就留下了永久的微观印记。当附近（3 米内）出现**活跃**沉渣时，这片组织会被同频激活，产生灼热感。沉渣停止活动或离开范围，灼热即刻消退。

**这不是能力，是伤。四条限制必须写死**：

1. **不可控**：关不掉，也调不灵敏。它是被动反应，不是探测术
2. **只报"有"**，不报方位、不报数量、不报强弱
3. **只在沉渣活跃时触发**。沉渣静止（如 041-047 那种已经停住的）不触发——所以 Ch.001 只有 043 让他发烫
4. **每触发一次，那道组织就再损伤一层**。这是虎口疤"七年一直没长好"的真正原因：不是愈合能力差，是它一直在被反复点着

**由此产生三条可利用的剧情后果**：

- 他不需要沉下去，也能知道"附近有活的东西在动"——这是他前期唯一一个不消耗感知负荷的预警手段
- 反过来说，**这道疤发烫的时候，对方也能察觉他**（同频是双向的）。这是他暴露的最大风险
- 这道疤是他与沉渣有过接触的**唯一物证**。2180 年那次接触，他自己解释不了。全书第一次让他怀疑"我到底是谁"的，就是这道疤

## 补丁 7：「散的」与「整的」（2026-10-30，Ch.008 老瘸口述）

> 解决的问题：沉渣既然是"崩解物"，为什么早先的描写里有"一克三百、按克卖"的零售，又有 043 这种"封存九十四年还在推"的整块？两者不是同一种东西。

### 两种形态

| | **散渣** | **整块** |
| -- | -------- | -------- |
| 形态 | 碎、散，手感像湿沙子 | 有边界，包在一层膜里，与周围组织长在一起但分得清 |
| 进入活体后 | 慢慢渗，渗到哪儿烂到哪儿 | 它自己不动，但周围组织会向它靠拢，靠过去就变成它 |
| 可否清除 | 能清，清不干净也能压住 | 不能清，只能"圈住" |
| 市场 | 有价。一克三百 | 无价，也没人买（买了的人活不长） |
| 分布 | 药巷、码头等投喂链末端 | 043 前臂中段；老瘸断腿截面 |
| 主角现状 | 能看见，看不清是什么 | 能看见膜，看不见膜里（半沉） |

### 三条写作约束

1. **不许把整块写成"活物"**。它不动、不攻击、不发声。它的恐怖来自"周围在向它靠"，不是来自"它会咬人"
2. **圈住 ≠ 治好**。老瘸用凝元境残境的干涉域把扩散一圈一圈圈住，只够挡住一条腿；他本人仍是残境，腿也没了
3. **一克三百只适用于散渣**。任何角色把整块拿去卖，都是不懂行，会被行内人当傻子或当诱饵

### 遗留问题（留给后文，不要提前解释）

- 整块是从散渣"长成"的，还是本来就是另一种东西？
- 为什么 043 那块推了九十四年，位置一点没动？
- 老瘸那块二十年"只慢不快"，是它在衰减，还是他在衰减？

## 补丁 8：许可登记与观测的可见性（2026-10-30，Ch.013-014 落地）

> 解决的问题：①为什么"能看"这件事可以被官方管理？②沈砚为什么不敢随便沉人？③为什么低境对高境完全无解？

### 一、许可登记制度

- 观微境以上必须在秩序局登记，进**沧城市微观许可持有者名单**，每年核验一次
- 名单在秩序局一楼大厅公示，任何市民可查。栏目：姓名、年龄、单位、许可等级、干涉域半径
- 未登记者从事与观测相关的有偿活动（"黑医"、代验伤、代判死因），按《微观许可条例》处罚
- 2187 年沧城市（870 万人口）在册数：

| 等级 | 人数 | 干涉域 |
| ---- | ---- | ------ |
| 凝元境·极域 | 9 | 20 米 |
| 凝元境·贯通 | 12 | 12 米 |
| 凝元境·初窥 | 26 | 5 米 |
| 观微境（各阶） | 约 3100 | 一律为零 |

> 观微境的干涉域只能是零——这不是懒，是层级锁：细胞层能看清，改不了。**这一条决定了本书前 60 章所有"看清了救不了"的场面**。

### 二、观测会被感知

- 观测是把感知压到某一层。**被观测的对象若也是结构师，会感到后颈发麻**——那是自己身上某一层被人压住了的本能反应
- 感知的强弱取决于三件事：
  1. **境界差**：差得越多越明显。观微境沉凝元境，对方立刻知道；同境互沉，双方都只是"有点不舒服"
  2. **停留时间**：超过三秒，从"发麻"变成"知道你在哪个方位"
  3. **看不看得进去**：被挡住时，对方感到的是"有人在推门"，比看进去更明显
- 对普通人观测，对方无感
- **写作约束**：
  - 沈砚对结构师发动观测，必须写出被察觉的后果，不许当无事发生
  - 反过来，沈砚自己也能感到被观测——这是后面被追踪的合理机制
  - 高境看低境同样会被感知，只是低境说不出那是什么感觉（"后颈凉了一下"）

### 三、结构师的身体是封闭的

- 观微境之后，身体各层的排列会被人为"梳理"过，越往高层越紧
- 低境沉高境，像推一只装满水的皮袋：表面是软的，往里水就顶上来
- **硬顶的代价**：鼻腔出血、太阳穴跳、视野边缘发灰。顶得越深，代价越重
- **补块**：结构师受过重伤并被高境者修复后，受损区会留下排列异常的细胞区，边缘有一圈极细的线，像补过的墙。这是识别"有人给他治过"的唯一肉眼证据（Ch.013 周牧右臂）

## 补丁 9：下沉的实操参数（Ch.053–060 定稿）

### 一、观微 → 凝元的门槛

| 项 | 数值 | 来源 |
| -- | ---- | ---- |
| 崩解面积 | **三成（下限）**；四成二才稳 | Ch.058 池渊口述 |
| 层级 | 分子级（胶原链、细胞膜脂双层被拆） | Ch.056 |
| 状态 | 必须**清醒 + 睁眼**；一处昏迷即整次作废 | 铁律 2 |
| 方向 | 崩解必须有"来向"——碱从上面来，断口就全朝上 | Ch.054/056 |
| 时间 | 四分钟到四分半（三成碱液、40℃） | Ch.054 |
| 死亡率 | 六成（三成面积）；三成面积者有一半死在 72 小时内 | Ch.058 |

### 二、"疼是门"（本节最重要）

感知的边界由痛觉划定。**疼痛被压住，感知就停在原层**，无论意志多强。

- 因此不能用麻醉、止痛药、冰敷、分神
- 因此"忍"是错的：忍是抵着，抵着就进不去；正确动作是**松开、让疼全部进来**
- 因此下沉者稀少：常人在这个痛度会休克，休克即作废

### 三、固化的真实做法（三阶段）

1. **排块**：给断链一个"样子"，珠子自己归位。第一块极慢（一根链 40 分钟），之后靠"已排好的那块"当模板，越来越快
2. **抹边界**：块与块之间的界线**是他自己画的**。不是剪断，是"忘掉"——一句"你们本来是一条"，界线四十秒就松
3. **合上**：到点（72 小时整）身体里"箱子盖落下"，全身成一块，无一条界

> 反面教材：把五十四块"串起来"＝五十五样东西在跑，它们会打架，打完退回原处。

### 四、代价的真实机制

固化时身体按优先级分配资源：心→肺→肝→肾→脑，**四肢排最后**。

- 代价不是"烧坏"，是"被抽干"：烧过却排不上用的地方，会被身体当材料抽走
- 抽干的组织最终与老瘸断腿里"那块整的"同构：一圈一圈死的组织，在缩
- 唐枝画格时发现的旧疤（肩胛骨下月牙疤）＝别人给他"排"过的痕迹，与虎口同类

### 五、写作约束

- 下沉/固化期间主角**不能走动**。大面积创面 + 体温 33 度 + 心跳 44，只能躺或靠
- 每一次"加速"必须有机制原因（模板、界线是自己画的），不能靠"他咬牙更快了"
- 干涉域 5 米 ≠ 能打。三米推一只铁钉半公分；五米只能"感觉到"

## 补丁 11：崩解线的行为（Ch.060 定稿）

- 速度：一天十二米三（四公里半/年）
- 界碑：2171 年立；立碑时线在七十二公里外
- 位置：6/2 在界碑内 91 米；7/20 在 100 米
- **异常点不是距离，是方向**：少掉的三根电线杆在东侧，说明线是往西退的
- 崩解是"被从某个方向推倒"：断口朝向能读出推力来向。这一条同时是沈砚 056 自救的依据、060 判断方向的依据、第二卷追踪的依据
