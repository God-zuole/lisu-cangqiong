# 韩枢

## 一句话

结构师联盟，凝元境极域。他活了太久，所以对什么都不着急。他说话永远礼貌、永远准确、永远在给选择——但他给的每个选择都通向同一个地方。

## 语言指纹

| 项 | 特征 |
| -- | ---- |
| 平均句长 | 中长，非常流畅，几乎不用短句。他的句子没有毛边 |
| 词汇层级 | 混合。学术词和日常词无缝切换，听起来很有教养 |
| 跑不跑题 | 不跑。但他会先回答一个你没问的问题，再回过头答你问的 |
| 比喻来源 | 生意、园艺、医学。他说人像"一块地"，说培育像"间苗" |
| 口头禅 | "你可以拒绝。""这不重要。""我们换个说法。" |
| 紧张时 | 不会紧张。**他唯一的变化是停顿变长** |
| 生气时 | 不会生气。他只会更礼貌，礼貌到让人发冷 |

## 三段台词

**开场（他在你屋里，像坐在自己家）**

> "你这屋子潮。墙根那一圈返碱，是从下往上走的，说明地基里的水没断。修不好，除非把地掀了。"
>
> 他抬眼看沈砚。
>
> "我说这个，不是闲话。我是在告诉你，有些东西你看着是表面，其实是底下。你这三年查的每一件事，都是墙根那一圈白霜。"

**招揽（把残忍说成体贴）**

> "我不要求你做什么。每个月，看三个人。你看，你说，我听着。你不说也行，你就坐着。"
>
> "这三个人会怎么样。"
>
> "会怎么样，不取决于你看不看。他们已经在那儿了。你唯一能决定的是——他们死的时候，有没有人知道他们是怎么死的。"
>
> 他停了一下。
>
> "你可以拒绝。真的。我从来不勉强人。勉强来的东西，长不好。"

**从不生气的那种可怕**

> "你把刀放下了。很好。"
>
> "我没放下。"
>
> "你放下了。"韩枢说，"你举了三十七秒，然后放下了。一个人真要杀我，不会数秒。"

## 他不会说什么

- 不会说脏话
- 不会提高音量
- 不会说"你必须""你没有选择"。他永远说"你可以不"
- 不会撒谎——但他会把全部真相说出来，然后让你自己选错

## 与沈砚的关系动态

买家。他想要的是沈砚的眼睛，不是沈砚的人。他给钱、给位置、给他母亲的治疗——每一笔都记在账上，从不催债。
