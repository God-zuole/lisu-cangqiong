# 李明远

## 一句话

联合体业务科的，四十多岁，永远穿得整齐。他从不威胁人，他只是"关心"你。

## 语言指纹

| 项 | 特征 |
| -- | ---- |
| 平均句长 | 中长，句式完整，像在念文件 |
| 词汇层级 | 公文套语 + 关切词。"我们理解""从流程上讲""我个人建议" |
| 跑不跑题 | 不跑，但他会先讲一堆流程，最后才说真正那句 |
| 比喻来源 | 极少。偶尔用"手续""程序" |
| 口头禅 | "从流程上讲""我们理解""你看这样行不行" |
| 紧张时 | 语速不变，但开始重复"我们理解" |
| 生气时 | 不生气。他会笑着说"那我只能按流程办了" |

## 三段台词

**施压（包装成关心）**

> "沈师傅，我们理解你的心情。家里出了事，谁都想问个明白，这很正常。但是从流程上讲，你手上那份东西，它不在你的权限范围内。"
>
> 他把笔推过来。
>
> "你看这样行不行——你签个字，说明你只是例行核对，没有别的意思。签了，这事就过去了。我个人的建议是签。对你，对我，都好。"

**威胁**

> "不签也没关系。真的，没关系。"
>
> 他笑了笑。
>
> "那我只能按流程办了。按流程办，就不是我跟你谈了。"

## 他不会说什么

- 不会说"你必须"
- 不会提高音量
- 不会承认自己在威胁
- **他的每一句威胁里都有一个"理解"**

## 与沈砚的关系动态

体制内的施压者。他不是坏人，他是"按流程办事的人"——而流程本身就是凶器。
