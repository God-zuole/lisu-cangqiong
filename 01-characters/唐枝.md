# 唐枝

## 一句话

二十四岁，修东西的。她相信什么都能修，只是还没找到哪儿坏了。

## 语言指纹

| 项 | 特征 |
| -- | ---- |
| 平均句长 | 中等偏长。一句话能塞三件事，中间用"然后"串起来 |
| 词汇层级 | 技术口语。"拆开""装回去""卡住了""这个件不对"——她习惯拿修东西的词说人 |
| 跑不跑题 | **爱跑。** 问一句能答三句，第三句往往是自己想到的、跟问题没关系的 |
| 比喻来源 | 机械、电路、旧货。她说人"这块儿接触不良"，说局面"拆开看看就知道了" |
| 口头禅 | "等一下。""你刚才说……""不对。"（"不对"是她的思考声，频率极高） |
| 紧张时 | **话更多。** 越怕越说，说到最后自己都停不下来 |
| 生气时 | 不骂人。变成一句一句地追问，逼对方给理由 |

## 三段台词

**平常**

> "你这个泵不对。声音发闷，是叶轮那儿蹭了。我拆开看看——你别动，你一动我更找不着了。"

**紧张**

> "沈砚。沈砚你听见没有。你要是听见了就敲一下，敲一下就行。你别不说话，你不说话我不知道你是睡着了还是……你敲一下。你敲一下我就不问了，真的，我一句话都不问了。"

**生气**

> "你说四成能活。四成。你是怎么算的？你把哪四成算进去了？你算的时候有没有把自己算进去——不是算你活下来，是算你死了以后我怎么办。"

## 她不会说什么

- 不会说"节哀""想开点"这类安慰话。她只会做事
- 不会用成语。她的词汇里没有"进退两难"
- 不会一句话说完就闭嘴。她一定要补一句

## 与沈砚的关系动态

她一开始是委托人（认领父亲遗物），后来变成唯一在场的人。她对他的态度是：我看得见你在往下掉，我拉不住，但我不走。
