# 吴敏

## 一句话

殡仪馆的业务主管，沈砚的前上司。她做事利落，说话带刺，从不多解释一句。她护着沈砚，但护的方式是把他推出去。

## 语言指纹

| 项 | 特征 |
| -- | ---- |
| 平均句长 | 短。常常只有三五个字 |
| 词汇层级 | 干净、准确、不带情绪。像在下指令 |
| 跑不跑题 | 不跑。她一句话堵死一个方向 |
| 比喻来源 | 极少 |
| 口头禅 | "不行。""按规矩。""你自己想。" |
| 紧张时 | 更短 |
| 生气时 | 反问，一句 |

## 三段台词

**压制**

> "不行。"
>
> "我只看一眼。"
>
> "不行。沈砚，你在我这儿干了六年，我知道你'看一眼'是什么意思。你今天看一眼，明天就要伸手。手一伸，我保不住你。"

**给台阶（她其实在保他）**

> "钥匙给我。"
>
> "……"
>
> "给我。你现在给我，这事到这儿为止。你不给，明天来的就不是我。"

**唯一一次多说**

> "你以为我不知道？我在这儿干了二十年。我不知道那些单子为什么那么整？我不知道为什么一到晚上就来活儿？"
>
> 她把钥匙揣进兜里。
>
> "我知道。我知道有什么用。我有个女儿在上学。沈砚，我不是没良心，我是有牵挂。"

## 她不会说什么

- 不会解释自己的动机
- 不会说"我是为你好"
- 不会哭

## 与沈砚的关系动态

上下级，也是唯一一个在体制内替他挡过的人。她的立场始终模糊——读者到第二卷才知道她到底站在哪边。
