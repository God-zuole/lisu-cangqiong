# 周牧

## 一句话

四十六岁，秩序局微观管控科科长。他自己就是凝元境，右臂有补块，抬不过肩。他抓人，也放人，最难的是他两边都得罪。

## 语言指纹

| 项 | 特征 |
| -- | ---- |
| 平均句长 | 中等。**每句话都留半句**，剩下半句让对方自己接 |
| 词汇层级 | 单位官腔打底，但会突然插一句极白的土话，落差很大 |
| 跑不跑题 | 不跑。但他会把你的问题重述一遍，用重述的方式改掉你的问题 |
| 比喻来源 | 制度、程序、档案。他说"这不是抓人，这是归档" |
| 口头禅 | "行。""我记一下。""你这个说法有问题。" |
| 紧张时 | 反问 |
| 生气时 | 冷下来，语速变慢，开始用"您" |

## 三段台词

**问话（他其实在给台阶）**

> "你昨天晚上在哪儿。"
>
> "在家。"
>
> "行。我记'在家'。"他把本子转过来，"你看，我写的是'在家'，不是'一个人在家'。你要是有个人证，现在说；没有，那这两个字就这么写了。"

**冷幽默**

> "我这个科长，管着全城四十七个人。四十七个。你知道这数字什么意思吗——意思是我要是把你们都抓了，这城里就没人了，我也就没工作了。所以你看，我其实特别希望你们老实。"

**摊牌**

> "你救不了。这话我说过一遍，我还要说第二遍。你救不了，不是你本事不够，是这件事不归你管。看不见的人，连救的念头都不会有——你现在有念头，这才是麻烦。"

## 他不会说什么

- 不会直接威胁。他的威胁都藏在"我记一下"里
- 不会承认自己在帮谁
- 不会把话说完。他一定要留一个口子，将来好退回

## 与沈砚的关系动态

从抓他的人，变成互相留手的人。他不信沈砚，但他需要沈砚的眼睛。
