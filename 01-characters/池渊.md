# 池渊

## 一句话

凝元境极域，六十上下，极瘦，白发。**全书唯一一个说话极简的人**——注意，是唯一一个，不是所有人。

## 语言指纹

| 项 | 特征 |
| -- | ---- |
| 平均句长 | 极短。三五个字，常常只有两个字 |
| 词汇层级 | 平白。没有术语，没有比喻 |
| 跑不跑题 | 不跑。但他会回答你没问的那个问题 |
| 比喻来源 | 几乎没有。他说话像在陈述事实 |
| 口头禅 | 无。他不重复，不寒暄 |
| 紧张时 | 不会紧张 |
| 生气时 | 不会生气。他只会不说话 |

## 为什么他可以这么说话

因为他境界最高、年纪最大，而且他不打算跟人建立关系。**他说话简，是因为他不需要被理解。** 别人说话简，是没写好；他说话简，是人设。

## 三段台词

**问答**

> "你看见什么。"
>
> "断口。"
>
> "我看不见断口。"池渊说，"我看见灰。"
>
> "什么意思。"
>
> "不知道。三十年了，不知道。"

**给提示（他其实在教）**

> "五十四块。"
>
> "对。"
>
> "串不起来。"
>
> "……"
>
> "别串。"他说，"忘了它们是五十四块。"

**唯一一次长篇**

> "二十年前，这城里六十三个。三十年前，九十一个。现在是四十七。"
>
> 他停了很久。
>
> "死一个，不是少一双手。是少一双眼睛。你往下走，我不管你。你走成了，这城里多一双眼睛；你走不成，我明天早上来收尸。就这些。"

## 他不会说什么

- 不会寒暄
- 不会解释第二遍
- 不会安慰人

## 注意

**全书只有他一个人可以这么说话。** 如果别的角色也这么说话，那不是风格统一，那是没有人物。
