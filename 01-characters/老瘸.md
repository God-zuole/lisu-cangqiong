# 老瘸（王守义）

## 一句话

六十一岁，殡仪馆干了四十年，左腿从膝盖以下没了。他知道这行的全部规矩，也知道全部脏事。他说话像在试探，因为四十年里说错一句话就没了命。

## 语言指纹

| 项 | 特征 |
| -- | ---- |
| 平均句长 | 短句为主，但会突然拉出一长句骂人或打比方 |
| 词汇层级 | 殡葬行话 + 底层粗话。遗体叫"活儿"，火化叫"走炉"，那种整块的叫"整的" |
| 跑不跑题 | **绕。** 你问他 A，他先答 B，再拐到 C，最后回到 A——但那时的 A 已经是另一个问题了 |
| 比喻来源 | 身体、殡葬、残肢。他拿自己的腿打比方，一点不忌讳 |
| 口头禅 | "你听我说。""这个事儿吧……""操。" |
| 紧张时 | 话变少，开始反问 |
| 生气时 | 骂，但骂得脏、短，一句就完 |

## 三段台词

**试探（他其实在问"你知不知道")**

> "你这手，抖什么。"
>
> "没抖。"
>
> "抖了。你别跟我犟，我看人抖了四十年——躺着的那些不抖，站着的才抖。你要是没看见什么，你不会抖。"

**交代**

> "我跟你讲，这行有个规矩。活儿进来，你只管修，别问是谁。问了，你就成了这链条上的一环。我年轻时候问过一次。就一次。"
>
> 他顿了一下。
>
> "后来我这条腿就没了。你说巧不巧。"

**骂人**

> "操。你他妈早干什么去了。人死了你才来问疼不疼——他疼的时候你在哪儿。"

## 他不会说什么

- 不会讲大道理。他要讲的道理都包在一个具体的事里
- 不会说"我帮你"。他只会给你一样东西，然后说"这玩意儿你别让人看见"
- 不会一次说完。他要分三次给，第三次给的时候人已经快不行了

## 与沈砚的关系动态

先是街面上能说话的一个人，后来变成唯一一个知道内情还愿意讲的人。他护着沈砚，但方式是把他往外推。
