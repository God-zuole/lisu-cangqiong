# 赵九

## 一句话

药巷的中间人，五十来岁，缺一颗金牙。他做的是把货从上面接下来、再散到下面的活。他油，他怕，但他有个儿子。

## 语言指纹

| 项 | 特征 |
| -- | ---- |
| 平均句长 | 短。一句一顿，像在报账 |
| 词汇层级 | 纯市井，全是买卖话。"这个价""你给个实底""咱不绕" |
| 跑不跑题 | 中。他会突然插一句跟自己有关的抱怨，然后马上回到价上 |
| 比喻来源 | 钱、买卖、赌。"这买卖不亏""你这是要我的命价" |
| 口头禅 | "兄弟""你听我说""这个数" |
| 紧张时 | 开始开玩笑，笑得很难看 |
| 生气时 | 不骂。他会把价往上抬 |

## 三段台词

**报价**

> "三千。"
>
> "八百。"
>
> "八百？兄弟，八百我连本都回不来。你摸摸这包装，铝箔的，一层一层压的，这不是散货。三千，我给你抹个零，两千八。"
>
> "八百。"
>
> "……你这人。行。八百。"
>
> 他把东西往桌上一推。
>
> "不过我跟你讲，八百的货，你别指望它能救命。八百的货，只够你看清楚它是什么东西。"

**紧张时开玩笑**

> "你别老盯着我看。你这么看我，我心里发毛。我这人胆小，从小就胆小，我妈说我这胆子跟兔子似的……哎你说，兔子胆儿大不大？我小时候养过一只，那玩意儿……算了，你要问什么你问。"

**提到儿子（他唯一不油的时候）**

> "我有个儿子。六岁。"
>
> "……"
>
> "我不是跟你说这个求你什么。我就是……你要是哪天听说我出事了，你别管我。你去看看他。他叫赵小满，满月的满。"

## 他不会说什么

- 不会说"我不知道"。他一定会给一个数、一个说法，哪怕编
- 不会长篇大论讲道理
- 不会在儿子的事上绕

## 与沈砚的关系动态

卖家。他怕沈砚，也靠沈砚。他知道自己在这条链上是什么位置——跑腿的，跑腿的迟早要跑丢。
