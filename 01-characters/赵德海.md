# 赵德海

## 一句话

殡仪馆看大门的，记了十四年账。他这辈子最大的本事是"什么都没看见"，最大的毛病是管不住嘴。

## 语言指纹

| 项 | 特征 |
| -- | ---- |
| 平均句长 | **长，非常长。** 一句话能绕三圈，中间全是"我跟你说""你知道吧" |
| 词汇层级 | 纯市井。没有术语，全是"那个""这个""反正" |
| 跑不跑题 | **极度跑题。** 问他一句，他能从自己小时候讲起，讲到一半想起来"对了你刚才问我什么来着" |
| 比喻来源 | 基本不打比方。他只会举例子，而且例子都跟自己有关 |
| 口头禅 | "哎哟""我跟你说""你知道吧""我这人你知道的" |
| 紧张时 | **话爆炸。** 越怕说得越多，最后变成自我辩解 |
| 生气时 | 不生气。他只会更小声、更快地说 |

## 三段台词

**日常絮叨**

> "哎哟，你来啦。今天这个天，说冷不冷说热不热的，我这一早上打了三个喷嚏。你说这楼里是不是潮？我跟你说，我早就说过这楼里潮，他们不听，说是什么……什么通风系统。通风系统顶什么用，我那屋里的墙皮都起来了，一块一块的，跟下雪似的……你找我有事？"

**怕事（自我辩解）**

> "我什么都不知道。我一个看大门的，我能知道什么。我就是个记本子的，谁进来我记一笔，谁出去我记一笔。我记了十四年，一笔都没错过——你要查你查本子，本子上有。我这个人，我这个人就是老实，老实人吃亏啊，但是老实人睡得着觉……"

**说漏了**

> "那个……那个姓赵的，他来得勤。也不是勤，一个月来两三回吧。他每次来都带东西，带的什么我不知道，我不看。我这人不看别人带的东西——哎，不过他有一回把一个包落这儿了，我给他收着，后来他也没来拿……我是不是不该说这个？"

## 他不会说什么

- 不会一句话答完
- 不会用书面语
- 不会主动说"我看见了什么"。他一定先声明自己什么都没看见，然后才说

## 与沈砚的关系动态

同事情谊，但随时会为了自保把他卖出去——这不是坏，是弱。
