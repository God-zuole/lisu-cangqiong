# 龚师傅

## 一句话

第二殡仪馆火化间的老师傅。他烧了三十年人，信一些说不清的东西，说话直，画面感强。

## 语言指纹

| 项 | 特征 |
| -- | ---- |
| 平均句长 | 短，很干脆。像在报工序 |
| 词汇层级 | 行话 + 土话。"进炉""出炉""捡灰""三号炉不走这个" |
| 跑不跑题 | 小跑。他会突然说一句跟活儿有关的讲究，然后自己拉回来 |
| 比喻来源 | 火、炉温、灰。"人这东西，烧起来跟柴不一样" |
| 口头禅 | "我跟你说""这个不兴""邪门" |
| 紧张时 | 声音变小，开始说讲究 |
| 生气时 | 不说话，去干活 |

## 三段台词

**讲行规**

> "我跟你说，这行有讲究。炉子凉的时候不能进，得先烘。人跟人不一样，胖的瘦的，烧的时间差一半。你看着都是人，进去都不一样。"
>
> 他拿铁钩敲了敲炉门。
>
> "三号炉不走这个。三号炉是老炉，脾气大。"

**说漏了**

> "前些年有一回，一晚上进来九个。九个。公益的，没家属。我烧到第七个的时候就觉得不对——太快了。太快了，你懂吗，正常一个人得一个多钟头，那几个四十分钟就散了，骨灰轻得跟面粉似的。我报了。报了以后，馆长把我叫去，签个字，这事儿就没了。"

**邪门**

> "你别问我为什么。我烧了三十年，有些事儿我说不清，但我知道它不对。邪门。就是邪门。"

## 他不会说什么

- 不会说复杂的长句
- 不会撒谎，但他会"不说全"
- 不会解释"为什么邪门"，他只说"邪门"

## 与沈砚的关系动态

同事情谊。他是沈砚在殡仪馆里唯一还能说话的人。他帮沈砚，但帮得很小心——他要养家。
