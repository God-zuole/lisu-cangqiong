## 一、先说结论：为什么读不进去

不是因为文笔。是五个结构问题，按严重程度排：

| # | 问题 | 具体表现 |
| - | ---- | -------- |
| 1 | **没有贯穿全卷的目标** | 前 20 章目标是"查这七具遗体是什么"，查完就断了；中段换成"查这条产业链"，查完又断了。目标每二十章换一次，读者跟不上 |
| 2 | **主角一直被动** | 60 章里他主动做的决定只有三次（050 说"我要能动手"、053 定日期、056 开始烧）。其余时间在被查、被打、被抄家、被跟踪 |

| 6 | **所有人一个腔** | 因为 `01-characters/` 里只有沈砚一份档案，"声线约束"这条规则从来没被执行过 |

前三条是主线问题，后三条是写法问题。写法已经写进 `rules.md`（第零节、第三节、第四节），这一份只解决主线。

## 二、新主线

### 一句话

**一个能看见人体内部的殡仪馆修理工，为了留住母亲，把自己一步一步卖进那条他正在查的黑产链。**

动词是**卖**。

### 三层

| 层 | 内容 | 推进节奏 |
| -- | ---- | -------- |
| 表层：**钱** | 母亲住在城东护理院，一个月两千四。他停职后月入一千二。钱什么时候烧完，读者一直在算 | 每章都能推进 |
| 中层：**手段** | 母亲的病不是普通病——血管壁上有沉积。能改这个的只有结构师。他得变成结构师 | 每十到十二章一个台阶 |
| 深层：**底线** | 每一个能给他钱或手段的人，都要他先做一件事：看一个不该看的人、签一份不该签的字、沉默一次。他每卖一次，就少一块自己 | 全书 |

### 关键调整

**「查妹妹」从主线降为动机。** 它是他为什么知道这条链存在的原因，是燃料，不是引擎。

**「变强」从目的降为手段。** 他往下沉不是为了变强，是因为那是唯一能救母亲的路。

这两条一换，主线就只有一个方向，读者不会跟丢。

### 为什么旧主线不行

旧主线是"查真相"。查真相有天然缺陷：

- **可以查完。** 查完读者就走了。所以必须不停地加新线索、新谜题，越加越散。
- **主角不需要改变。** 查案的人从头到尾是同一个人，只是知道得更多。读者看不到他付出代价。
- **对手可以一直躲。** 真相在暗处，反派不必出场，于是四十章没有一张脸。

"卖"这条线没有这些毛病：**卖不完**（母亲一直需要钱）、**主角每章在变**（越卖越少）、**买家必须露面**（要交易就得见面）。

### 每幕的任务分配（重点）

每一幕给主角**一个明确的、可失败的目标**，而不是"继续查"：

- 一幕：**别被发现。** 失败——被停职。
- 二幕：**凑够母亲半年的钱。** 失败——钱凑够了，但代价是手上沾了事。
- 三幕：**换一个更好的买家。** 失败——韩枢给的价他付不起。
- 四幕：**救老瘸。** 失败——老瘸被"搬空"。
- 五幕：**活过七十二小时。** 成功——但废了右手。

**每一幕都以失败告终（第五幕除外，但它也不是赢），这是这本书的骨架。** 读者每三十章会发现："他又输了，但他往前挪了一步。"

### 三条规律（本轮修正过的）

1. **四字是标签长度，不是句子长度。** 三字像口语，五字像散文。档案柜、价目牌、火化单备注栏，全是四个字。
2. **标题自己要是一个异常。** "七具同批"不该成立（正常该一具一具来），"一克三百"不该成立（人不该论克卖），"切口自合"不该成立。标题陈述的事实越是不该成立，越有劲。
3. **数字只在它是关系时用，不在它是数量时用。** 一克三百是价格关系，七具同批是批次关系，都成立；"四十一小时""缺失十二克"只是数，一律毙。
